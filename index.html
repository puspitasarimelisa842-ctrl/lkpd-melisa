Fase 1: pengenalan konsep vps & cloud

1. Shared Hosting

Layanan hosting dimana sebuah server fisik dibagi bersama sama dengan banyak pengguna lain

2. Dedicated Serve

Seluruh sumber daya server fisik di dedikasikanpenuh hanya untuk satu penyewa atau pengguna saja

3. Amazon lightsail

Layanan virtual private server (vps) dari aws yang di rancang khusus untuk pemula atau proyek sekala kecil/ menengah

4. Amazon EC2 ( Elastic Compute Cloud)

Layanan web berskala besar yang menyadiakan kapasitas komputasi virtual server yang dapat dibubah ukurannya di cluod AWS
