Fase 1: Pengenalan Konsep VPS & Cloud

1. Shared Hosting

Layanan hosting dimana sebuah server fisik dibagi bersama-sama dengan banyak pengguna lain.

2. Dedicated Server

Seluruh sumber daya server fisik didedikasikan penuh hanya untuk satu penyewa atau pengguna saja.

3. Amazon Lightsail

Layanan Virtual Private Server (VPS) dari AWS yang dirancang khusus untuk pemula atau proyek skala kecil/menengah.

4. Amazon EC2 (Elastic Compute Cloud)

Layanan web berskala besar yang menyediakan kapasitas komputasi virtual server yang dapat diubah ukurannya di cloud AWS.
